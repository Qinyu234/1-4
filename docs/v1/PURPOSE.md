# 任务目的：Fairy Orbit Periodic Search Platform v1

## 要解决什么问题
在牛顿力学下，为「一颗行星 + 四个正四面体对称妖精」寻找准周期 / 换位周期（编织）轨道，而不是写一个可玩的世界模拟器。

## 为什么现在做
世界观与光照都依赖「四点能不能跳舞」这一物理前提；先建成可扫参、可评分、可存档的实验平台，才能后续优化。

## 验收标准
- [ ] Leapfrog 五体积分可跑，并记录能量 / 角动量
- [ ] 正四面体 Rodrigues 对称传播速度；2D `(v_rad, v_tan)` 近逃逸网格搜索
- [ ] OrbitEvaluator：换位误差 + 碰撞 + 能量漂移 → score
- [ ] 候选写入 `orbit_library/`；第一实验脚本可端到端跑通并出图
- [ ] pytest 全绿

## 明确不做
- 相对论、光线弯曲、气候、魔法规则、复杂服务器模型
- Stage2 深度局部优化（仅留 stub）
- 天空效果（光照 / 遮挡 / 潮汐）指标
